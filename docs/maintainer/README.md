# Maintainer Docs

These docs are for people changing LicenseTrack itself.

- `architecture.md` maps the current module boundaries, ownership rules, and
  implementation guardrails.
- `style-contract.md` records coding and review conventions for human and
  AI-assisted changes.

Operator documentation lives in `wiki/`. Extension and plugin author material
lives in the neighboring `extension-authors/` and `plugin-authors/` folders.
