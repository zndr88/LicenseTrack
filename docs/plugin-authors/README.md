# Plugin Author Docs

These docs are for authors building installable Plugin Host v1 packages.

Start with:

- `plugin-author-guide.md` for package layout, manifest rules, permissions,
  settings, runtime protocol, suggestions, and plugin licensing guidance.
- `plugin-host-v1-contract.md` for the shipped v1 host contract.
- `plugin-host-post-v1-notes.md` for future-direction notes beyond v1.

API/webhook integrations that run outside LicenseTrack belong in
`../extension-authors/`.
