Document Repository

What it is
The Document Repository keeps supporting evidence connected to the right licensing record or procurement step. License-owned documents include EULAs, entitlement certificates, and other license-specific supporting files. Procurement documents include Quote, Purchase Order, and Invoice files. Procurement documents are scoped to the pending order that produced the licenses, or to the specific license they were uploaded from. The PO number is descriptive metadata, not the sharing key.

How it works
License documents attach to individual licenses and are managed through the license detail panel. When you open a license, the documents section loads automatically and groups files by category. From there you can upload new files, download existing ones, or delete files you no longer need. Downloading triggers a file save in your browser.

Editors and admins can request processing for an uploaded document from the document row when an active document processor webhook is configured and a document.processing integration capability is available. This does not process the file inside LicenseTrack and it is not an installed plugin action; it emits an audited document_action.requested event for configured external processors.

External processors can return suggested values as document processing results. LicenseTrack shows pending suggestions in the Documents section, marks documents with recent processing status, preserves accepted/rejected/superseded history, and only applies selected suggestions after an editor or admin accepts them.

Current document processing applies to supported license fields and existing custom fields through the license review flow. It does not yet support generic plugin buttons in sourcing or pending-order modals, automatic draft license creation, or multi-line quote creation before conversion.

Each document has a category. License-owned categories include EULA, entitlement, and other. Procurement categories are Quote, Purchase Order, and Invoice. The category helps you identify what a file represents without opening it.

Quote documents can be uploaded during the sourcing stage against a sourcing request. They can also be uploaded from the Pending Orders page when a pending order line item still points back to its originating sourcing request. In both cases, quote ownership stays with the sourcing request until the pending order is converted. Quote documents can be downloaded or deleted from the sourcing request while that evidence remains sourcing-owned.

Purchase Order documents can be uploaded, downloaded, and deleted on a pending order during pending-order work. When you convert a pending order into licenses, LicenseTrack copies quote documents from the originating sourcing request into that pending order's procurement document set. This preserves the quote evidence on every license created from the same pending order without requiring the quote to be uploaded repeatedly for every line item.

When you convert a pending order to licenses and upload an invoice at the same time, LicenseTrack stores that invoice as a pending-order-scoped procurement document. Every license created from that pending order can see the Quote, Purchase Order, and Invoice files in its document section. A later separate pending order that reuses the same PO number does not automatically inherit those files.

Documents uploaded directly from a license detail panel with procurement categories are scoped to that license. They are visible on that license without becoming shared evidence for every other license that happens to have the same PO number.

The total number of documents visible to a license is shown as a count in the License Registry table. The count includes license-owned documents plus procurement documents scoped to that license or to the pending order that created it, and it updates after document changes.

LicenseTrack stores document files on the server's local filesystem. If a license is deleted, documents owned by that specific license are permanently deleted as well. Pending-order-scoped procurement documents remain attached to the procurement bundle that created the licenses. Sourcing quote files are stored separately under the sourcing request until they are copied into the pending order's procurement document set during license conversion.

All document upload paths use the shared storage validator for file size and extension checks. License document uploads also apply a MIME type allow-list; procurement and sourcing uploads use the shared size and extension checks.

Key concepts
Document category - the classification assigned to a document, such as Quote, Purchase Order, Invoice, EULA, entitlement, or other.

Quote document - procurement evidence uploaded to a sourcing request and later copied into the pending order's procurement document set.

Purchase Order document - procurement evidence uploaded during pending-order work and stored against that pending order.

Invoice document - supplier billing evidence uploaded during pending-order conversion and stored against that pending order.

Procurement bundle - the pending-order document scope shared by licenses created from the same pending order.

Document count - the number of files visible to a license, including license-owned documents and procurement documents scoped to that license or its source pending order.

Who can use it
Admins and Editors can upload, download, and delete license-owned documents and procurement documents where the workflow allows it. They can also upload quote documents during sourcing or pending-order work. Viewers can view and download documents on licenses in their assigned departments, subject to download permissions configured by an admin.

Things to know
- Deleting a license deletes license-owned documents attached to that license permanently. Pending-order-scoped procurement documents are not license-owned and may remain visible to other licenses created from the same pending order.
- Quote documents belong to sourcing requests until conversion, then are copied into the pending order's procurement document set.
- Sourcing quote documents and pending-order purchase-order documents each have their own download and delete paths before license conversion.
- Quote, Purchase Order, and Invoice procurement documents are shared across licenses created from the same pending order.
- Reusing a PO number on a separate pending order does not automatically reuse the earlier pending order's documents.
- Document storage is local to the server. There is no cloud storage integration; documents are only accessible through LicenseTrack itself.
