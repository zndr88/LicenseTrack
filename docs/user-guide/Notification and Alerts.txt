  Notifications and Alerts

  What it is
  Notifications and Alerts keep budget owners, managers, and users informed about licenses that are expired, approaching expiry, or have incomplete records — both inside LicenseTrack and by email — so that
  nothing lapses unnoticed.

  How it works
  LicenseTrack runs a notification check once per day at a configurable time. When the check runs, it classifies licenses into three categories: expired, expiring, and incomplete. Licenses that have already
  passed their end date appear as expired. Licenses approaching expiry within the configured alert window appear as expiring. Licenses that are missing required fields appear as incomplete. Already-renewed
  licenses and legacy licenses are excluded from all notifications — they will never appear in alerts regardless of their dates.

  On the email side, LicenseTrack sends two types of message. Budget owners receive a per-owner alert listing the licenses relevant to them, grouped by purchase order number. Maintenance licenses in that alert
   show their parent license's software description rather than their own, so the email remains readable without requiring the recipient to cross-reference records. A separate manager digest is sent
  summarising the overall picture. The intro and sign-off text in both email types can be customised by an admin in the global settings. Before any email is sent, LicenseTrack checks the recipient's address
  against an allowed domain list — addresses outside the permitted domains are silently skipped.

  LicenseTrack also prevents duplicate scheduled emails: it records the date of the last successful scheduled notification run and will not send another scheduled run on the same calendar day, even if the scheduler is restarted. An admin can trigger a manual notification run from the settings page when they need to send outside the scheduled window or retry after a failed scheduled attempt.

  Inside the application, the Notifications page shows the same expired, expiring, and incomplete alerts for your current session's access scope. Clicking any alert opens the relevant license directly in the
  detail panel. A badge in the navigation counts the number of outstanding alerts so you can see at a glance whether anything needs attention without visiting the page.

  Key concepts
  Expiring — a license whose end date falls within the configured alert window but has not yet passed.
  Expired — a license whose end date has already passed.
  Incomplete — a license that is missing one or more required fields.
  Budget owner alert — an email sent to the person responsible for a set of licenses, grouping those licenses by PO number.
  Manager digest — a summary email sent separately to give managers an overview of the notification run.
  Domain whitelist — the list of email domains that LicenseTrack is permitted to send notifications to.

  Who can use it
  All roles can view in-app notifications, scoped to the licenses within their access. Only Admins can configure notification settings, customise email text, or trigger a manual notification run. Email
  recipients do not need to be LicenseTrack users — budget owners receive alerts at whatever address is recorded on their licenses.

  Things to know
  - The scheduler will not send more than one successful scheduled email notification run per calendar day. Manual notification runs are explicit admin actions and can be used to retry after a failed scheduled run.
  - Already-renewed and legacy licenses are excluded entirely. If a license you expect to see in notifications is missing, check whether it has been marked as renewed or flagged as legacy.
  - The domain whitelist is enforced before any individual email is sent. A budget owner whose email address is on a domain not in the whitelist will receive no alert, with no error or warning shown in the
  application.
  - Maintenance licenses appear in budget owner emails under their parent license's software description. If a maintenance license appears to have the wrong name in an email, check the parent record rather
  than the maintenance record itself.
