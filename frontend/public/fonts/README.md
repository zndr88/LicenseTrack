# Bundled fonts (offline / no external CDN)

This directory vendors the webfont files used by the frontend so deployments can run without reaching out to `fonts.googleapis.com` / `fonts.gstatic.com`.

Font families used:
- Space Grotesk (weight 700)
- Outfit (weights 300/400/500)
- DM Mono (weights 400/500)

These families are distributed under the SIL Open Font License, Version 1.1.
See `OFL-1.1.txt` in this directory.

Source used for the bundled webfonts:
- Google Fonts CSS endpoint:
  - `https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@700&family=Outfit:wght@300;400;500&family=DM+Mono:wght@400;500&display=swap`
